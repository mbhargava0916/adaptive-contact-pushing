# Adaptive Contact Pushing

A reproducible Isaac Sim benchmark for fixed-action planar pushing under geometry and contact changes.

## Module 1A

First milestone: validate one scripted push and record initial/final object pose. Then expand to 30 controlled trials.

## Environment

- Isaac Sim 5.1 (Windows)
- Python for offline analysis

## Status

Scaffold only; simulation integration is not yet implemented.

## Research question

How does a fixed pushing action degrade when object geometry, friction, and initial conditions vary?
